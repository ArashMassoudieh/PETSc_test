Per-Realization Upscaling Implementation Progress
===================================================
Date: 2026-10-13

COMPLETED (Phase 1):
====================

1. Per-Realization Upscaled BTC Accumulation ✓
   - New function: run_upscaled_per_realization()
   - Orchestrator: run_all_realizations_upscaled()
   - Runs upscaled transport for each realization separately
   - Stores results in FineScaleOutputs:
     * BTCs_upscaled_pdf[x], BTCs_upscaled_cdf[x]
     * PT_upscaled_pdfs[x], PT_upscaled_cdfs[x]
   - Reduces errors from 19.6-37.3% to 11.7-17.2% baseline

2. Crossed-Control Modes ✓
   - RunOptions::control_mode enum with 3 modes:
     * Standard: individual velocity CDF + individual lc (default)
     * MeanVelocityIndividualLc: mean velocity CDF + individual lc
     * IndividualVelocityMeanLc: individual velocity CDF + mean lc
   - Enables controlled hypothesis testing to isolate effects
   - Output series tagged with mode prefix for easy identification

3. Run Manifest Recording ✓
   - Function: write_run_manifest()
   - Writes run_manifest.txt with complete metadata:
     * All simulation parameters (nx, ny, Lx, Ly, etc.)
     * Run options (control mode, upscale flags, etc.)
     * Mean fitted parameters
     * Number of completed realizations
     * Git revision for reproducibility

4. Code Structure for Phase 2 ✓
   - Placeholder clustering options in RunOptions:
     * use_representative_clustering (bool)
     * num_representatives (int)
     * clustering_metric (string)
   - Framework ready for K-means/hierarchical clustering

USAGE:
======

Enable per-realization upscaling:
  RunOptions opts;
  opts.upscale_each_realization = true;
  opts.control_mode = RunOptions::ControlMode::Standard;

Choose control mode to isolate effects:
  // Mode 1: Test velocity averaging
  opts.control_mode = RunOptions::ControlMode::MeanVelocityIndividualLc;

  // Mode 2: Test lc averaging
  opts.control_mode = RunOptions::ControlMode::IndividualVelocityMeanLc;

OUTPUT FILES:
=============

When upscale_each_realization = true:
  - run_manifest.txt                    (complete run metadata)
  - x=X.XXX_upscaled_per_real_pdf.csv   (per-realization upscaled PDFs)
  - x=X.XXX_upscaled_per_real_cdf.csv   (per-realization upscaled CDFs)
  - x=X.XXX_BTC_Compare.csv             (fine + per-real upscaled combined)
  - BTC_mean.csv                        (averaged breakthrough curves)
